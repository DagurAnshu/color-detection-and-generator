# color-detection-and-generator
# 🎨 AI Color Studio

AI-powered color detection and color generation web app built using Streamlit, OpenCV, NumPy, and Pillow.

## 🚀 Features

- 📤 Upload image and detect dominant color
- 🎛️ Generate custom colors using RGB sliders
- 🎨 Live color preview
- 📊 RGB intensity visualization
- #️⃣ HEX color generation
- ⬇️ Download generated color image
- 🖼️ Interactive Streamlit UI

---

## 🛠️ Technologies Used

- Python
- Streamlit
- OpenCV
- NumPy
- Pillow (PIL)

---

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/DagurAnshu/color-detection-and-generator.git
```

Go to project folder:

```bash
cd color-detection-and-generator
```

Install dependencies:

```bash
pip install streamlit opencv-python pillow numpy
```

---

## ▶️ Run the App

```bash
streamlit run app.py
```
